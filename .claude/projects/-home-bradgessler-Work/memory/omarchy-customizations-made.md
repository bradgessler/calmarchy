Everything lives under ~/.config, ~/.local/bin, and ~/.local/state; nothing in /usr/share/omarchy. Snapshot as of 2026-11-14.

**Git:** config is tracked in a bare repo at `~/.dotfiles` with `$HOME` as work tree (untracked files hidden). Use `~/.local/bin/dotfiles` exactly like git; `dotfiles add <new file>` for anything new, commit after each change with the Co-Authored-By trailer. Remote: public github.com/bradgessler/calmarchy (created 2026-11-17 as omarchy, renamed; Brad named the project "Calmarchy"), push after committing. README at `~/.github/README.md` (shown on GitHub) with screenshots in `~/.github/screenshots/`; `omarchy-dotfiles-setup` does the non-file setup (gsettings, Inter, Firefox profile + /etc policy, theme). Keep both in sync when features change. Brad can't stand tabs; stacks replace them.

**Keybindings (in ~/.config/hypr/bindings.lua, appended blocks):**
- **Panels model (2026-11-14):** windows live only in panels: full, left, right, top, bottom, tl, tr, bl, br. `omarchy-snap <panel> [address]` places a window; `omarchy-snap --frame-of <address>` names its panel (6px tolerance). Ctrl+Alt + Left/Right/Up/Down/Return/U/I/J/K snap. A `window.open` hook in bindings.lua runs `omarchy-panel-place <addr>`: windows tagged omarchy-mode-opened* (Omarchy leaves dialogs untagged) go on top of the previously focused window's panel, or full on an empty workspace. Super+drag release runs `omarchy-panel-drop` (≥40% onto another window = its panel; pointer in top 1/8 = full; else left/right half). This is a starting point Brad wants to iterate on.
- Super+Tab / Alt+Tab (+Shift reverses): `omarchy-window-cycle` rotates the stack under the active window, else cycles workspace windows (`cycle_next` + `bring_to_top`). Super+` also runs `omarchy-stack-cycle`.
- Super+Left/Right/Up/Down: `omarchy-pane-focus` (nearest window in that direction, topmost of its stack; past the edge Left/Right go to workspace ±1 within 1-5, no wrap).
- Super+N: `omarchy-new-window` (Cmd+N; terminals get same-cwd terminal, firefox/chromium/nautilus `--new-window`, else gtk-launch the desktop entry). The open hook stacks it on the focused window's panel.
- Super+L unbound (Cmd+L muscle memory kept cycling layouts). Replaced Omarchy defaults: Super+Tab (next workspace), Alt+Tab (focus next), Super+arrows (directional focus), Super+mouse:272 (now hold/release pair).

**Windowing:** default layout floating (`omarchy-hyprland-workspace-layout-default floating`; per-workspace files in ~/.local/state/omarchy/workspace-layouts/ override it). Title bars off: looknfeel.lua disables hyprbars on load and on `config.reloaded`, because Omarchy's floating mode enables them after user config. Dock autohidden. Stacks = windows in the same panel (cycle script uses intersection-over-union ≥0.8; no Hyprland groups, Brad rejects tabs). Workspaces 1-5 persistent (input.lua `hl.workspace_rule`) so swipes have targets.

**Trackpad (input.lua):** natural scroll, scroll_factor 0.15, 3- and 4-finger horizontal workspace swipe (distance 350, cancel_ratio 0.3, min_speed_to_force 25; 5 broke it), 4-finger pinch out/in runs `omarchy-show-desktop show|hide`. The 4-finger-up scratchpad gesture was removed (empty special workspace looked like a broken blurred screen). looknfeel.lua re-enables the workspaces slide animation for swipe inertia.

**Look:** the same faint 12% white hairline on every window, not a focus signal (no borders looked weird; a brighter active border "sucks"), shadow only on the active window (inactive transparent); focus = active shadow only (range 18, 45% black, offset 0 4); menu cards keep a 35% white hairline; NO dim_inactive (Brad: dimming alters colours, bad for comparing photos); reapplied after floating mode on every reload (Omarchy's 16pt shadows on every window smudged the 8pt gaps), rounding 3 (2026-11-17: "slight", not clownish macOS; 6 was rejected as too round). Theme: hand-made Monokai at ~/.config/omarchy/themes/monokai/, wallpaper 3-tree-tops.webp. Fonts: UI Inter, terminal Berkeley Mono; `~/.config/fontconfig/conf.d/60-ui-sans.conf` maps sans/system-ui/-apple-system to Inter and, via `prgname` quickshell/Hyprland, the shell's hard-coded "monospace" to Inter; gsettings font-name 'Inter 11'.

**Gotchas:**
- `hyprctl dispatch` takes Lua here: `hyprctl dispatch 'hl.dsp.focus({ workspace = 2 })'`. Old dispatcher syntax errors.
- An open `omarchy-menu` layer silently blocks all focus changes; check `hyprctl layers`, fix with `omarchy-menu close`.
- `wtype` keys don't trigger Hyprland binds; test via `hyprctl dispatch 'hl.dsp.exec_cmd("...")'`. No click tool exists; to screenshot an open tray, temporarily default `expanded: true` and restart.
- Plugin PanelWindow geometry changes need `omarchy restart shell`; hot reload doesn't recreate windows.
- `omarchy theme set monokai` resets the wallpaper; restore with `omarchy-theme-bg-set ~/.local/state/omarchy/current/theme/backgrounds/3-tree-tops.webp`.
- `hyprctl clients` order isn't z-order; verify with grim. `grim -g` takes logical coords; full grim output is physical (×2).
- `pkill -f <pattern>` from the Bash tool kills its own shell; use `pkill -x` or hyprctl close.
- Root steps without a terminal: `pkexec bash -c '...'`.

**Why:** none of this is obvious from the files alone. **How to apply:** check here before changing or undoing anything; see [[user-omarchy-setup-preferences]].
