# Brad's Omarchy config

Tracked in place with a bare repo: `~/.dotfiles` is the git dir, `$HOME` is the
work tree, and only files added explicitly are tracked. Use the `dotfiles`
wrapper in `~/.local/bin` exactly like `git`:

    dotfiles status
    dotfiles add ~/.config/hypr/bindings.lua
    dotfiles commit -m "Tweak bindings"

Not tracked on purpose: the licensed Berkeley Mono fonts in
`~/.local/share/fonts`, browser profiles beyond userChrome.css and user.js,
and backup files.

Settings that live outside files: `gsettings set org.gnome.desktop.interface
font-name 'Inter 11'`, `gsettings set org.gnome.desktop.interface cursor-size 20`, `omarchy dock autohide on`, the `inter-font` package,
and Firefox's default search engine (set in the Firefox UI).
